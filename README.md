## 🛠️ Tecnologias Utilizadas

### **Frontend & UI/UX**
* **HTML5 Semântico:** Estruturação focada em acessibilidade e SEO.
* **CSS3 Moderno:** Utilização de CSS Grid, Flexbox, Variáveis CSS e Design Responsivo sem uso de frameworks pesados.
* **JavaScript (ES6+):** Manipulação do DOM, controle do menu mobile e scroll spy.

### **Foco Backend & Engenharia (Demonstrados nos Projetos)**
* **Linguagens & Frameworks:** Python, Flask RESTful.
* **Banco de Dados:** SQL, SQLite, PostgreSQL, Migrações de Schema.
* **Ferramenta & Workflow:** Git, Git Flow (branching model), GitHub Pages para deploy contínuo.
